# 6. Conclusion

Ce projet de veille technologique a permis de concevoir et de valider une architecture de télémétrie automobile. En combinant un Raspberry Pi Zero 2 W connecté à un adaptateur OBD2, une API mASP.NET Core et une interface temps réel Blazor Server, le project AutoPi remplace les applications payantes.

Ce projet a été une opportunité pour découvrir le potentiel d'un Raspberry Pi, ainsi que pour apprendre ASP.NET, Blazor et SignalR. Cette expérience permet de comprendre concrètement comment lier le développement logiciel avec la capture de données physiques.
